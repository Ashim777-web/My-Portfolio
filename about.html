About

Still early, deliberately serious about it.

Introduction

I'm a cybersecurity student who spends most of my free time in a home lab, breaking things on purpose so I understand how they're supposed to work. I got into security the way a lot of people do — through curiosity about how systems fail — and stayed for the discipline it demands.

Education

I'm currently pursuing a degree with a focus on computer science and information security fundamentals, supplementing coursework with self-directed labs, CTFs, and vendor-neutral certifications in progress.

Cybersecurity interests

My interest sits at the intersection of blue and red team work: I like building detection logic as much as I like trying to evade it. Right now that shows up as a home SOC lab on one side and web application testing on the other.

Current learning journey

I'm working through networking fundamentals, Linux administration, and Python scripting in parallel with applied security labs — treating the fundamentals as non-negotiable rather than something to skip past to get to "the interesting part."

Technical philosophy

Understand before automating

I don't script something until I've done it manually enough times to know what the script should actually check.

Document everything

If a lab isn't written up, it didn't happen. Documentation is the actual deliverable, not an afterthought.

Break it to understand it

The fastest way I've found to understand a defense is to try to get past it in a controlled environment.

Goals

Short term, I'm aiming for a SOC analyst or junior penetration testing internship where I can apply these fundamentals under real constraints. Long term, I want to specialize — most likely in detection engineering or offensive security — once I've built enough breadth to make that choice deliberately rather than by default.
