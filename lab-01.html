Isolated VM Pentesting Lab

Lab #1 · Sept 2026

Objective

Build a safe, fully isolated environment to practice on, so nothing I do can touch my real network or any machine outside the lab.

Environment

  • VirtualBox running on my own laptop
  • Kali Linux VM — 192.168.xx.xxx
  • Metasploitable 2 VM (intentionally vulnerable target) — 192.168.xx.xxx
  • VirtualBox Host-only Network adapter connecting the two, with no route to the internet or my home network

Tools

VirtualBoxKali LinuxMetasploitable 2

Methodology

  1. Installed VirtualBox and downloaded the Kali Linux and Metasploitable 2 images.
  2. Created both VMs and configured a Host-only Network adapter on each, isolating them from the internet and my home Wi-Fi.
  3. Checked each VM's assigned IP on the host-only network.
  4. Verified connectivity between the two VMs with a ping test.
kali@kali — ping test
$ ping -c 4 192.168.xx.xxx
4 packets transmitted, 4 received, 0% packet loss

Result

Isolated lab network confirmed working

Successfully created an isolated VirtualBox pentesting environment. Kali Linux (192.168.xx.xxx) can communicate with Metasploitable 2 (192.168.xx.xxx) over a Host-only network with 0% packet loss.
