Lab 02 — Linux Fundamentals for Security

Sept 2026 · 7 min read Beginner
LinuxPermissionsNetworking
Contents
Objective Environment 1. File & Directory Mgmt 2. File Permissions 3. Users, Groups & sudo 4. Processes & Services 5. Basic Networking Result What I Learned Screenshots

Objective

Learn basic Linux commands and security concepts that are useful for cybersecurity and penetration testing.

Environment

  • OS: Kali Linux 2026.2
  • Virtualization: Oracle VirtualBox
  • Network: VirtualBox Host-Only
  • Kali IP: 192.168.56.101
  • Metasploitable IP: 192.168.56.102

1. File & Directory Management

Created a working directory and files using:

bash
mkdir cyberlab
touch notes.txt
ls -l

I also used echo and cat to write and read information from a file.

2. Linux File Permissions

Checked file permissions using:

bash
ls -l notes.txt

Tested different permission modes:

bash
chmod 600 notes.txt
chmod 644 notes.txt

What I learned

Linux permissions control access for the owner, the group, and others. For example, 644 gives the owner read/write access while the group and others have read-only access.

3. Users, Groups & sudo

Checked the current user:

bash
whoami

Checked user and group information:

bash
id
groups

Tested elevated privileges:

kali@kali:~
$ sudo whoami
root

What I learned

sudo allows an authorized user to execute commands with elevated privileges.

4. Processes & Services

Viewed running processes:

bash
ps aux | head

Searched for a specific process:

bash
ps aux | grep bash

Checked running services:

bash
systemctl --type=service --state=running

What I learned

Processes are currently running programs, while services are background processes that provide system functionality. Understanding running processes and services is important when performing system enumeration.

5. Basic Networking

Checked network interfaces:

bash
ip addr

My Kali machine had: 192.168.56.101/24

Checked the routing table:

bash
ip route

Tested connectivity to my Metasploitable VM:

kali@kali:~
$ ping -c 4 192.168.56.102
4 packets transmitted
4 received
0% packet loss

Result

Fundamentals confirmed, connectivity holding

Successfully practiced fundamental Linux commands related to files, permissions, users, privileges, processes, services, and networking. The Kali Linux VM successfully communicated with the Metasploitable VM over the isolated Host-only network.

What I Learned

  • Basic Linux filesystem navigation
  • Creating and managing files
  • Understanding Linux permissions
  • Using chmod
  • Understanding users and groups
  • Using sudo
  • Viewing processes and services
  • Identifying network interfaces
  • Understanding basic routing
  • Testing network connectivity with ping
